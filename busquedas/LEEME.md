# Búsquedas científicas

Tutorial en seis etapas: fuentes, revistas y cuartiles, calidad metodológica, formulación de preguntas, construcción de cadenas y selección de estudios.

El constructor admite ocho marcos (PICO, PICOT, PEO, PECO, PCC, SPIDER, PICo y CoCoPop), ejemplos de salud y educación, y salidas para búsqueda booleana genérica, PubMed, Scopus y Web of Science. Entrega borradores, no estrategias validadas: los descriptores se comprueban en cada tesauro y la cadena se prueba en cada base. La ficha se puede copiar o descargar en TXT; no se guarda al recargar.

## Verificación

Desde la raíz del sitio:

```bash
node busquedas/check.cjs
```
